# Цели для бесплатного урока - Яндекс Метрика

## Обзор

Добавлены цели для отслеживания поведения пользователей на странице с бесплатным уроком (урок 1/1) для залогиненных, но неоплаченных пользователей.

## Добавленные цели

### 1. Загрузка страницы урока
- **Событие**: `free_lesson_page_viewed`
- **Где отправляется**: `pages/lesson/[lessonId].tsx`
- **Когда**: При загрузке страницы урока 1/1
- **Параметры**:
  - `lessonId` - ID урока (1)
  - `lessonTitle` - название урока

### 2. Приветственное видео с Ирэной

#### 2.1. Запуск видео
- **Событие**: `intro_video_started`
- **Где отправляется**: `src/components/component2/component2.tsx`
- **Когда**: При запуске приветственного видео
- **Параметры**:
  - `videoTitle` - название видео
  - `videoDuration` - длительность видео
  - `autoplay` - автозапуск (false)

#### 2.2. Прогресс просмотра
- **Событие**: `intro_video_progress`
- **Где отправляется**: `src/components/component2/component2.tsx`
- **Когда**: При достижении 25%, 50%, 75%, 90% просмотра
- **Параметры**:
  - `progress` - процент просмотра
  - `currentTime` - текущее время
  - `videoTitle` - название видео

#### 2.3. Завершение видео
- **Событие**: `intro_video_completed`
- **Где отправляется**: `src/components/component2/component2.tsx`
- **Когда**: При завершении просмотра (≥95%)
- **Параметры**:
  - `duration` - длительность видео
  - `videoTitle` - название видео

### 3. Видео урока

#### 3.1. Запуск видео урока
- **Событие**: `video_started`
- **Где отправляется**: `src/components/video_player/videoPlayer.tsx`
- **Когда**: При запуске видео урока
- **Параметры**:
  - `stageId` - ID этапа
  - `stageName` - название этапа

#### 3.2. Прогресс просмотра урока
- **Событие**: `lesson_video_progress`
- **Где отправляется**: `src/components/video_player/videoPlayer.tsx`
- **Когда**: При достижении 25%, 50%, 75%, 100% просмотра
- **Параметры**:
  - `progress` - процент просмотра
  - `currentTime` - текущее время
  - `stageId` - ID этапа
  - `stageName` - название этапа

#### 3.3. Завершение видео урока
- **Событие**: `video_completed`
- **Где отправляется**: `src/components/video_player/videoPlayer.tsx`
- **Когда**: При завершении просмотра видео урока
- **Параметры**:
  - `stageId` - ID этапа
  - `stageName` - название этапа

### 4. Открытие методички
- **Событие**: `workbook_opened`
- **Где отправляется**: `src/components/lesson_header/lessonHeader.tsx`
- **Когда**: При клике на кнопку "Open the workbook"
- **Параметры**:
  - `userPaid` - статус оплаты пользователя
  - `pdfType` - тип PDF (full/limited)
  - `lessonId` - ID урока
  - `stageId` - ID этапа

### 5. Клик на заблокированные этапы
- **Событие**: `locked_stage_clicked`
- **Где отправляется**: `src/components/course_list_item/courseListItem.tsx`
- **Когда**: При клике на заблокированный этап урока
- **Параметры**:
  - `lessonId` - ID урока
  - `lessonTitle` - название урока
  - `stageNumber` - номер этапа
  - `redirectTo` - куда происходит редирект (profile)

## Техническая реализация

### Использование хука useMetrica
```typescript
import { useMetrica } from 'next-yandex-metrica';

const { reachGoal } = useMetrica();

// Отправка события
reachGoal('event_name', { param1: 'value1', param2: 'value2' });
```

### Контрольные точки для видео
- **Приветственное видео**: 10%, 25%, 50%, 75%, 90%
- **Видео урока**: 25%, 50%, 75%, 100%

### Уникальность событий
События отправляются только один раз для каждой контрольной точки с помощью `dataset` атрибутов:
```typescript
const key = `checkpoint_${checkpoint}`;
if (!video.dataset[key]) {
  video.dataset[key] = 'true';
  reachGoal('event_name', params);
}
```

## Аналитика и отчеты

### Ключевые метрики для отслеживания:
1. **Конверсия просмотра** - соотношение загрузок страницы к просмотрам видео
2. **Вовлеченность** - процент завершения видео
3. **Путь к оплате** - клики на заблокированные этапы
4. **Использование материалов** - открытие методички

### Рекомендации по анализу:
- Отслеживать воронку: загрузка → видео → методичка → оплата
- Анализировать точки выхода из видео
- Мониторить популярность заблокированных этапов
- Изучать время, проведенное на странице

## Настройка в Яндекс Метрике

1. Войдите в аккаунт Яндекс Метрики
2. Выберите счетчик `100786060`
3. Перейдите в раздел "Цели"
4. Создайте цели для каждого события:
   - `free_lesson_page_viewed` - Загрузка бесплатного урока
   - `intro_video_started` - Запуск приветственного видео
   - `intro_video_progress` - Прогресс приветственного видео
   - `intro_video_completed` - Завершение приветственного видео
   - `lesson_video_progress` - Прогресс видео урока
   - `workbook_opened` - Открытие методички
   - `locked_stage_clicked` - Клик на заблокированный этап

## Дополнительные возможности

### Параметры событий
Можно расширить события дополнительными параметрами:
- Время сессии
- Источник трафика
- Устройство пользователя
- Географическое положение
- Статус оплаты

### Кастомные события
Для специфических бизнес-процессов можно добавить:
- `lesson_abandoned` - покидание урока
- `video_paused` - пауза видео
- `workbook_downloaded` - скачивание методички
- `payment_intent` - намерение оплатить

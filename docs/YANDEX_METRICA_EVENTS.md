# Яндекс Метрика - События и отслеживание

## Обзор

В проекте настроена Яндекс Метрика с ID счетчика `100786060` для отслеживания пользовательского поведения и ключевых событий.

## Конфигурация

### Основная инициализация
- **Файл**: `pages/_app.tsx`
- **ID счетчика**: `100786060`
- **Параметры**:
  - `clickmap: true` - карта кликов
  - `trackLinks: true` - отслеживание переходов
  - `accurateTrackBounce: true` - точный подсчет отказов

## Отслеживаемые события

### 1. Регистрация пользователя
- **Событие**: `user_registered`
- **Где отправляется**: 
  - `src/components/modal_register/Register.tsx`
  - `src/components/modal-form-register/modal-form-register.tsx`
- **Когда**: При успешной регистрации (заполнены все поля и форма отправлена)

### 2. Вход в систему
- **Событие**: `user_login`
- **Где отправляется**: `src/components/modal-form-auth/modal-form-auth.tsx`
- **Когда**: При успешном входе в систему

### 3. Успешная оплата
- **Событие**: `payment_successful`
- **Где отправляется**: `pages/api/stripe/webhook.ts`
- **Когда**: При успешной обработке платежа через Stripe webhook
- **Дополнительно**: Передается ID пользователя

### 4. Просмотр главной страницы
- **Событие**: `homepage_viewed`
- **Где отправляется**: `src/components/hero/Hero.tsx`
- **Когда**: При загрузке компонента Hero (главная страница)

### 5. Просмотр страницы курсов
- **Событие**: `courses_page_viewed`
- **Где отправляется**: `pages/courses.tsx`
- **Когда**: При загрузке страницы курсов

### 6. Просмотр курса/урока
- **Событие**: `course_viewed`
- **Где отправляется**: `src/components/course_list_item/courseListItem.tsx`
- **Когда**: При клике на курс в списке
- **Параметры**: 
  - `lessonId` - ID урока
  - `lessonTitle` - название урока

### 7. Начало просмотра видео
- **Событие**: `video_started`
- **Где отправляется**: `src/components/video_player/videoPlayer.tsx`
- **Когда**: При начале воспроизведения видео
- **Параметры**:
  - `stageId` - ID этапа
  - `stageName` - название этапа

### 8. Завершение просмотра видео
- **Событие**: `video_completed`
- **Где отправляется**: `src/components/video_player/videoPlayer.tsx`
- **Когда**: При завершении воспроизведения видео
- **Параметры**:
  - `stageId` - ID этапа
  - `stageName` - название этапа

## Техническая реализация

### Использование хука useMetrica
```typescript
import { useMetrica } from 'next-yandex-metrica';

const { reachGoal } = useMetrica();

// Отправка события
reachGoal('event_name');

// Отправка события с параметрами
reachGoal('event_name', { param1: 'value1', param2: 'value2' });
```

### Серверные события
Для событий, которые происходят на сервере (например, webhook Stripe), используется функция логирования:
```typescript
const sendYandexMetricaEvent = async (eventName: string, userId?: string) => {
  console.log(`📊 Yandex Metrica Event: ${eventName}`, userId ? `for user: ${userId}` : '');
};
```

## Аналитика и отчеты

### Ключевые метрики для отслеживания:
1. **Конверсия регистрации** - соотношение посетителей к зарегистрированным
2. **Конверсия оплаты** - соотношение зарегистрированных к оплатившим
3. **Вовлеченность** - просмотры видео и завершение уроков
4. **Путь пользователя** - последовательность действий от входа до оплаты

### Рекомендации по анализу:
- Отслеживать воронку: главная → курсы → регистрация → оплата
- Анализировать популярные уроки и этапы
- Мониторить отказы на каждом этапе
- Изучать время, проведенное на видео

## Настройка в Яндекс Метрике

1. Войдите в аккаунт Яндекс Метрики
2. Выберите счетчик `100786060`
3. Перейдите в раздел "Цели"
4. Создайте цели для каждого события:
   - `user_registered` - Регистрация
   - `user_login` - Вход в систему
   - `payment_successful` - Оплата
   - `video_completed` - Завершение видео

## Дополнительные возможности

### Параметры событий
Можно расширить события дополнительными параметрами:
- Время сессии
- Источник трафика
- Устройство пользователя
- Географическое положение

### Кастомные события
Для специфических бизнес-процессов можно добавить:
- `lesson_started` - начало урока
- `homework_submitted` - отправка домашнего задания
- `support_contacted` - обращение в поддержку
- `course_completed` - завершение всего курса

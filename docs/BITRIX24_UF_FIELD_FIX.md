# Исправление проблемы с полем UF в смарт-процессе счетов

## Проблема
Поле `ufCrm_SMART_INVOICE_1706948587230` не заполнялось при создании счетов в Bitrix24 через смарт-процесс.

## Причина
Использовалось неправильное название поля: `UF_CRM_1628621924030` вместо правильного `ufCrm_SMART_INVOICE_1706948587230`.

## Решение
Обновлены все файлы, где используется это поле:

### Файлы, которые были исправлены:
1. `pages/api/bitrix24/create-invoice.ts` - API для создания счетов
2. `pages/api/stripe/create-checkout-session-with-invoice.ts` - API для создания Stripe сессий с счетами
3. `src/utils/bitrix24.ts` - Утилиты для работы с Bitrix24
4. `pages/api/bitrix24/debug-invoice-fields.ts` - API для отладки полей

### Изменения:
```typescript
// Было:
'fields[UF_CRM_1628621924030]': '1013',

// Стало:
'fields[ufCrm_SMART_INVOICE_1706948587230]': '1013',
```

## Важные моменты
- Для смарт-процессов в Bitrix24 нужно использовать специальный формат названия поля
- Поле должно начинаться с `ufCrm_` и содержать уникальный идентификатор
- Значение поля остается `1013`

## Тестирование
Для тестирования исправления используйте страницу `/test-invoice`, которая теперь показывает:
- ✅ Проблема решена
- Правильное название поля: ufCrm_SMART_INVOICE_1706948587230
- Правильное значение поля: 1013
- Кнопка отладки для проверки полей

## Результат
Теперь поле `ufCrm_SMART_INVOICE_1706948587230` корректно заполняется значением `1013` при создании счетов в Bitrix24.
